# 0005. 圖片使用本地 SVG placeholder

- 狀態：已採用
- 日期：2026-11-18

## 背景

使用真站商品圖涉及版權，也違反「無外部呼叫」的精神；picsum 之類的外部圖庫則多了一個網路依賴，離線或對方服務異常時畫面就會壞掉。

## 決策

- 以本地 SVG 產生 placeholder，依分類套用不同色系，並在圖中顯示商品名或分類，讓版面密度與真站接近。
- 圖片尺寸比例依真站設定（商品卡 1:1、主視覺橫幅等），並預留 `width` / `height` 避免版面位移（CLS）。

## 影響

- 好處：零外部依賴、無版權疑慮、建置結果可完全重現。
- 代價：視覺擬真度低於真實商品圖；這是刻意的取捨，在 README 中說明。
